# RusSupport AI

Интеллектуальный помощник Support-отдела. Анализирует данные CRM и сообщения
рабочих чатов, выявляет расхождения, определяет риски и формирует ежедневную
сводку для руководителя.

> **Этап 1 (MVP):** локальное FastAPI-приложение с дашбордом, детерминированными
> правилами приоритизации и демонстрационными данными. Telegram-бот и реальный
> OpenRouter-подключение — на следующих этапах.

---

## Ключевые принципы предметной области

- CRM — официальный источник статусов.
- Сообщения из чатов — дополнительные свидетельства, но не официальное подтверждение.
- AI не меняет данные CRM самостоятельно.
- Предположения не выдаются за подтверждённые факты.
- Каждый вывод содержит источник (`crm` / `chat` / `rule` / `ai`) и основание.
- Приоритет определяется **детерминированными правилами**, а не мнением LLM.

## Структура проекта

```
app/
  main.py               # точка входа FastAPI, lifespan, монтирование роутеров
  config.py             # настройки из .env (pydantic-settings)
  api/routes.py         # API: /api/health, /api/cases, /api/summary
  dashboard/routes.py   # HTML-дашборд (главная страница)
  ai/
    base.py             # абстракция AIProvider
    openrouter_client.py# клиент OpenRouter (выключен на этом этапе)
    analyzer.py         # оркестрация правил + AI (опционально)
    prompts.py          # шаблоны промптов
  bot/                  # заглушки Telegram-бота (следующие этапы)
  services/
    prioritization.py   # детерминированные правила приоритизации
    summary.py          # сборка сводки и списка кейсов
    mock_data.py        # загрузка демонстрационных данных из JSON
  schemas/              # Pydantic-схемы (case, message, summary)
  database/
    models.py           # SQLAlchemy ORM-модели
    session.py          # асинхронный движок и сессия
  templates/            # Jinja2-шаблоны (base.html, dashboard.html)
  static/style.css      # стили дашборда
data/mock_data.json     # демонстрационные кейсы
tests/test_prioritization.py  # тесты правил приоритизации
```

## Установка и запуск (Windows PowerShell)

```powershell
# 1. Клонировать/перейти в проект
cd D:\EliasWaldman\tests\russupport-ai

# 2. Создать виртуальное окружение
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скопировать настройки
Copy-Item .env.example .env

# 5. Запустить сервер
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Если `py` недоступен, используйте полный путь к `python.exe`:
`C:\...\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`

## Настройки (.env)

Все параметры — в `.env` (см. `.env.example`). API-ключи в исходный код
не попадают. По умолчанию `AI_ENABLED=false` — приложение работает без
внешних API на детерминированных правилах.

## Известные ограничения этапа 1

- Telegram-бот не реализован (заглушки в `app/bot/`).
- OpenRouter-провайдер реализован, но выключен (`AI_ENABLED=false`);
  реальные вызовы появятся на следующих этапах.
- SQLite — только для демонстрации; для продакшена нужен PostgreSQL.
- Миграции БД не настроены (схема создаётся автоматически по моделям).
- Дашборд — только чтение; запись/изменение кейсов — следующие этапы.
- Аутентификация/авторизация отсутствуют.
